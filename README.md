# Калькулятор пеней по ставке ЦБ РФ

Бесплатный онлайн-инструмент для расчёта пеней, неустоек и процентов по ключевой ставке Банка России. Сайт статический — не требует сервера, базы данных и обслуживания.

## Что внутри

| Файл | Назначение |
|------|------------|
| `index.html` | Главный калькулятор пеней (1/300, 1/150, 1/360) |
| `penya-44-fz.html` | Пеня по 44-ФЗ для поставщиков |
| `penya-kommunalka.html` | Пеня за ЖКУ (1/300 → 1/130) |
| `penya-nalogi.html` | Пеня по налогам (ст. 75 НК РФ) |
| `procenty-395.html` | Проценты по ст. 395 ГК РФ |
| `stavka-cb.html` | История ключевой ставки |
| `kak-rasschitat-penyu.html` | Руководство с примерами |
| `sitemap.xml`, `robots.txt` | Техническое SEO |

## Как запустить бесплатно

> Vercel и Netlify для РФ недоступны (блокировка). Используйте проверенный GitHub Pages — он открывается из России без VPN.

### Способ 1 — GitHub Pages (рекомендуется, проверено из РФ)

1. Зарегистрируйтесь на https://github.com (бесплатно, работает из РФ).
2. Создайте новый репозиторий: **+** → **New repository**.
   - Имя репозитория: любое, например `peni-kalkulyator`.
   - Поставьте галочку **Public** (важно для Pages).
3. Загрузите файлы проекта: кнопка **Add file → Upload files** → перетащите все файлы из папки проекта → **Commit changes**.
4. Откройте **Settings** репозитория → раздел **Pages** (в меню слева).
5. В блоке **Build and deployment**: Source → `Deploy from a branch`, Branch → `main` / `(root)`, нажмите **Save**.
6. Через 1–2 минуты сайт появится по адресу `имя-пользователя.github.io/имя-репо/`.

### Способ 2 — Timeweb Cloud (российский хостинг)

1. Зарегистрируйтесь на https://timeweb.cloud (российский сервис, работает из РФ).
2. В панели управления есть бесплатные опции для небольших проектов — проверяйте актуальные тарифы на сайте.
3. Загрузите файлы проекта через панель или FTP, привяжите домен.

### Способ 3 — Neocities (бесплатно, доступно из РФ)

1. https://neocities.org — бесплатный статический хостинг.
2. Зарегистрируйтесь, загрузите файлы проекта через веб-интерфейс.
3. Сайт будет по адресу `имя-пользователя.neocities.org`.

## Настройка SEO (важно для трафика)

1. Зарегистрируйте сайт в **Google Search Console** (https://search.google.com/search-console) — бесплатно. Используйте способ проверки «HTML-файл» или «Мета-тег» (файл не нужен, если выберете мета-тег и добавите его в `<head>` каждой страницы).
2. В меню добавьте sitemap: `https://имя-пользователя.github.io/имя-репо/sitemap.xml`.
3. Зарегистрируйте сайт в **Яндекс Вебмастер** (https://webmaster.yandex.ru) — бесплатно.
4. Каждые 2–4 недели добавляйте новые статьи/страницы (калькуляторы под разные ниши) — так растёт поисковый трафик.

## Монетизация

1. **Сразу после запуска** — добавьте партнёрские ссылки (например, на сервисы электронного документооборота, онлайн-бухгалтерию, юридические консультации).
2. **После набора трафика (~1000+ визитов/мес)** — подайте заявку в:
   - **Яндекс РСЯ** (https://yandex.ru/adv) — реклама в Рунете;
   - **Google AdSense** (https://adsense.google.com) — международный трафик.

## Ограничения и честные ожидания

- При нулевых вложениях доход зависит от трафика. Первые визиты появятся через 1–3 месяца SEO.
- Суммы будут скромными: 1–6 тыс. ₽/мес на 5–20 тыс. визитов. Рост возможен за счёт новых страниц.
- Сайт не является юрконсультацией; расчёты носят информационный характер.

## Локальный запуск (проверка)

Просто откройте `index.html` в браузере — всё работает без установки.
